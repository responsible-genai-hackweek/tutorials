Landscape of tools

AI coding tools — what exists and how they differ.

Tool Form Models Notable trait
GitHub Copilot
 IDE extension Multi-provider Already in your editor — zero friction if your institution has a license
Cursor
 Forked IDE Multi-provider Purpose-built for agentic multi-file editing; stronger autonomous code changes than Copilot
Cline
 IDE extension Bring your own API Same editor comfort as Cursor but you supply the key — full control over model and spend
Claude Code
 CLI Anthropic Leaves the editor entirely; best for long autonomous runs and complex multi-step workflows
OpenAI Codex
 CLI OpenAI OpenAI-native CLI alternative; useful if your institution already has OpenAI rather than Anthropic credits
Crush
 CLI Bring your own Fully self-hostable and open-source; data stays on your machine by architecture, not policy
OpenCode archived
 CLI Bring your own Predecessor to Crush; widely cited in tutorials and documentation — included for reference
