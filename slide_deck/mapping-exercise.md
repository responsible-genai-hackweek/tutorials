# Where Does Your Work Sit?

A quick survey to help instructors tailor this week's content to you. There are no wrong answers — "I haven't used any AI tools yet" is useful information.

---

## Google Form Configuration

- Title: Where Does Your Work Sit?
- Description: Help us understand your current computing environment and AI tool experience so we can tailor this week's tutorials. Takes 2–3 minutes. All questions are optional.

---

## Questions

### 1. What is your primary computing environment?

Type: Multiple choice (select one)

- Personal laptop / desktop
- Institutional workstation (office machine, managed by IT)
- JupyterHub (CryoCloud, SMCE, or similar)
- HPC cluster (NCCS, Pleiades, institutional cluster)
- Cloud VM (AWS, GCP, Azure — self-managed)
- Multiple of the above equally
- Other

---

### 2. What editor or IDE do you spend the most time in?

Type: Multiple choice (select one)

- JupyterLab / Jupyter Notebook
- VS Code
- RStudio
- Terminal-based editor (vim, emacs, nano)
- PyCharm or other JetBrains IDE
- I mostly work in the terminal without an IDE
- Other

---

### 3. What is the typical sensitivity level of data you work with?

Type: Checkboxes (select all that apply)

- Publicly available data (open access, no restrictions)
- Pre-publication research data (not yet public, but no formal restrictions)
- Access-controlled data (requires login or data use agreement)
- Export-controlled or ITAR-restricted data
- Human subjects data (IRB-covered)
- I'm not sure what restrictions apply to my data

---

### 4. Which AI tools have you used for your work? (Not just tried once — actually used on a real task.)

Type: Checkboxes (select all that apply)

- ChatGPT, Claude, or Gemini in a browser (conversational chat)
- GitHub Copilot (autocomplete in IDE)
- Cursor or another AI-native IDE
- Cline (IDE extension with your own API key)
- Claude Code (command-line agent)
- OpenAI Codex (command-line agent)
- Crush (self-hosted command-line agent)
- Jupyter AI (AI features inside JupyterLab)
- An API directly (OpenAI, Anthropic, Google SDK)
- A locally-hosted model (Ollama, llama.cpp, etc.)
- I have not used any AI tools for my work yet
- Other

---

### 5. How are you currently accessing AI models?

Type: Multiple choice (select one)

- Free tier of a consumer product (ChatGPT free, Claude free, etc.)
- Personal paid subscription (ChatGPT Plus, Claude Pro, Copilot Individual, etc.)
- Institutional account or API key provided by my organization
- Self-hosted / running models locally
- I don't currently have access to any AI tools
- I'm not sure how my access is set up

---

### 6. What is your institution's current posture on AI for research?

Type: Multiple choice (select one)

- Actively supports it (provides accounts, API keys, or infrastructure)
- Permits it but provides no support or guidance
- Has issued guidelines or policies but no infrastructure
- Restricts or prohibits use for certain data types
- No official position that I'm aware of
- I'm not sure

---

### 7. What are you most hoping to be able to do by Friday?

Type: Short answer (open text)

Placeholder text: e.g., "Use an agent to help me refactor my data pipeline" or "Understand whether AI tools are appropriate for my data"

## Facilitator Notes

- Project the Google Forms "Responses" tab live as people submit
- Allow 2–3 minutes for completion (phones are fine)
- Spend 3–5 minutes on live synthesis: read back patterns, normalize the range
- Share the response summary with co-instructors after the session
- Optional: paste the response summary into an LLM for quick audience profile synthesis
